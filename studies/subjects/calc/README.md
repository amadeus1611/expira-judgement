# CALC: calculus

Subject ID `CALC`. Mentored book subject (same method as the other mentored tracks):
teach from the owner's copy of the book, cite chapter and section for every rule,
check each lesson's claims with `ej-study`, drill in an interactive HTML artifact,
and adapt to the pasted results log.

- Start here: [STATE.md](STATE.md), then [ROADMAP.md](ROADMAP.md) and [TRACKER.md](TRACKER.md).
- Source: OpenStax *Calculus Volume 1* (free PDF, openstax.org). Volumes 2 and 3 later.
  Edition, download date and table of contents are recorded only once the owner
  provides the PDF or sections; nothing is taught from memory.
- Why: an engineering entrance exam that covers calculus (see the `ENTRANCE` subject),
  then first-year engineering math. Exam names and dates stay out of this public repo.
- Related: `PHYS` uses calculus only where `CALC` has covered it.

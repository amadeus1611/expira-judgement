# BIO — Light general-biology review (optional)

Optional, light review: about two weeks, one pass, no deep study. Purpose: a possible
general-science part of an aptitude test. That part is unconfirmed (assumption, not a
fact). If the owner reports the test has no science section, close this subject.

- Source: OpenStax *Concepts of Biology* (free PDF). The owner supplies the PDF or
  sections. Teach only from the book, cite chapter and section for every claim, and
  check each lesson's claims with `ej-study`. No content from memory.
- Planned topics: cells, cell division, genetics and DNA, evolution, ecology, the main
  body systems. Book section mapping is recorded in [TRACKER.md](TRACKER.md) once the
  owner's copy is available.
- Method: short summary from the book, then an interactive HTML quiz artifact; the owner
  pastes the log back. Done = one clean cold pass plus one spaced review about a week later.

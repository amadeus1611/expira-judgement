# REASON — Abstract and verbal reasoning practice

Practice for an aptitude test whose sections are not published. Assumption (not a
confirmed fact): aptitude tests commonly include abstract reasoning (figure series,
matrices, odd-one-out, analogies), numerical reasoning and verbal reasoning. If the
official section list becomes available, re-plan around it.

There is no open textbook for this subject. Every drill item is practice written by
Claude for the learner, labelled as such, never an official or past exam item. Each item
has one defensible answer and a stated rule.

Method: interactive HTML drill (SVG figures) with a timer and a per-item seconds log the
learner pastes back. Learn the pattern types untimed first, then timed mixed sets. About
twice a week, 20–30 min. Track accuracy and seconds by pattern type; weight practice
toward weak types.

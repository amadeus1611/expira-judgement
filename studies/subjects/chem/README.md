# CHEM — General chemistry

  The owner will say which PDF they downloaded; its source ID is added to
  [SOURCES.md](../../SOURCES.md) then. The two books cover the same content in a different order.

  Exam names, schools and dates stay out of this repository.

  cites chapter and section for every rule, and checks each lesson's claims with
  [ej-study](../../../crates/ej-study/README.md). Nothing is taught from memory.
- Progress: [TRACKER.md](TRACKER.md) (by book section) and [STATE.md](STATE.md).
  Plan: [ROADMAP.md](ROADMAP.md).

  drills go in `drill/`. Neither exists until the first lesson.
- Shared prerequisites: units and algebra overlap with `TRIG` and `PHYS`; link to them,
  don't copy their progress here.
